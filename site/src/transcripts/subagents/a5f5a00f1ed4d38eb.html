### Rules with 3+ FPs — counter-examples to add

**`triad-swerve-budget` (0 confirmed, 3 FPs).** Scanners flag any three of anything. Two failure shapes: three separate *sentences* mistaken for a three-item clause, and a legitimate single instance flagged despite the budget being 1.

```
counter_example: |
"young, red about the ears, off his route and aware of it"
NOT a violation. This is one swerve-triad, and the budget is one per
scene — a lone instance is never reportable. The swerve item is also
grounded in the observable detail immediately before it (red ears)
rather than invented interiority. Only report when a scene contains
a SECOND three-item-in-one-clause list whose third item swerves to
interiority. Three consecutive sentences of blocking or of concrete
obligation ("There's a frost list… Marsh Barton and Upper Wold…
A sea-front is sitting off the coast…") are not this construction
at all, however many of them there are.
```

**`missing-qualifier` (0 confirmed, 3 FPs).** Fires on definite references whose sense is established elsewhere in the book.

```
counter_example: |
"The knot behind his breastbone did nothing." / "the tail of his own
Pellings rain" / "the nineteenth"
NOT violations. A bare definite noun is fine when (a) it names a
running motif whose sense was given in an earlier scene, (b) it
carries its own qualifier ("his own"), or (c) it is shorthand both
speakers demonstrably share and the scene pays off later ("Marsh
Barton, 19th, dry"). Report only when nothing in the file or the
established motif set tells the reader which thing is meant.
```

**`long-build-short-drop-budget` (1 confirmed, 3 FPs).** The scanner reports every instance rather than the overspend, and miscounts polysyndeton as a build.

```
counter_example: |
"He ate bread and cheese standing up at the dresser, and went to bed
at his usual hour, and lay awake longer than he meant to."
NOT a violation: a polysyndeton triad with no short drop sentence
after it. Also not violations: "This one did not slow. Second bend,
and he could see the sword." and "A girl." — both inside a budget of
two, and a drop that lands on the scene's actual turn is licensed.
Report only the surplus instances beyond two per scene, and name the
weakest as redacted: place, not the strongest.
```

**`aphorism-budget` (4 confirmed, 3 FPs).** The confirms all came from the judge; the scanner's own hits were mechanical statements.

```
counter_example: |
"A sea-front is not a cloud." / "a working that size takes what you
have and gives it back over days"
NOT violations. A general-sounding sentence is not an aphorism when
it is a technical distinction cashed out in particulars in the next
sentence, or a statement of what a working costs. The test is
portability: could this line be printed on its own and still mean
something? Mechanism, price, and elliptical continuations of a
specific sentence ("Most kings had not.") fail that test.
Conversely, DO look mid-sentence and mid-paragraph, not only at
paragraph-final position — the real overspends in this run were all
clauses buried inside teaching narration.
```

## 4. Constructions confirmed 2+ times — draft regexes (proposals only)

Offered as scanner seeds, not as rules; every one of these needs judge adjudication because the underlying rules are budgets or context-dependent.

```python
# description-list (4 confirms) — 3+ appositive/attributive items in one
# sentence on a character's or room's first appearance.
DESCRIPTION_LIST = re.compile(
r"(?:[a-z][^.;!?]{4,60}(?:,|;)\s+){3,}(?:and\s+)?[a-z][^.;!?]{4,60}[.;]"
)
# Gate: only run over sentences within N words of a character's first
# named appearance, or of a POV entry into a new location.

# system-terminology: "course" where the class is meant (2 confirms).
COURSE_FOR_CLASS = re.compile(r"\b(?:the|every|a|his|each)\s+course\b", re.I)
# Near-zero FP risk in this book: watercourse and "course of" are the
# only legitimate uses, both excluded by the determiner set.

# generalising-clause-budget (2 confirms) — outward generalisation to
# people-in-general, wherever it sits in the sentence.
GENERALISING = re.compile(
r"\b(?:most|every|any|all|no)\s+\w+s?\b[^.]{0,40}\b(?:had not|will|"
r"do not|does not|always|never)\b"
r"|\ba\s+\w+\s+will\s+\w+[^.]{0,60}\bfor as long as\b"
)
# Budget rule: report only instances beyond one per 3,500 words.

# cute-cryptic-closer (3 confirms) — final sentence of an author's note
# that is figurative rather than factual. Not regexable on its own;
# proposal is a positional extractor plus a judge prompt.
def note_closer(text: str) -> str:
return [s for s in re.split(r"(?<=[.!?])\s+", text.strip()) if s][-1]
# Then ask the judge: does this sentence state a fact, or gesture at
# one? Two of three confirms in this run were the note's LAST sentence,
# and the one scanner FP came from picking the wrong sentence — so
# anchoring positionally is the main win available here.

# implication-stopped-short (3 confirms) — a verb of learning/telling
# whose content is withheld.
IMPLICATION_WITHHELD = re.compile(
r"\b(?:you\s+learn|which\s+you\s+learn|say(?:s)?\s+you\s+should|"
r"there\s+is\s+only\s+one\s+answer)\b"
)
# Very low recall; treat as a hint generator for the judge rather than
# a scanner in its own right.
```
